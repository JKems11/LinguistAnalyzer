# LinguistAnalyzerAI 

**LinguistAnalyzerAI** to inteligentne narzędzie napisane w języku Python, które łączy analizę językową (NLP) z automatycznym tłumaczeniem. Projekt został stworzony, aby zademonstrować połączenie moich kompetencji technicznych oraz biegłości językowej (Native: PL/FR).

##  Główne Funkcje
* **Wielojęzyczność:** Automatyczne wykrywanie i tłumaczenie tekstów (Francuski, Angielski, Polski) przy użyciu `deep-translator`.
* **Analiza Sentymentu:** Wykorzystanie biblioteki `TextBlob` do określania wydźwięku emocjonalnego tekstu (pozytywny/negatywny/neutralny).
* **Przetwarzanie Plików:** Program wczytuje dane z pliku `tekst.txt` i generuje gotowy raport w pliku `raport.txt`.

##  Technologie
* **Język:** Python 3.10
* **Biblioteki:** `textblob`, `deep-translator`
* **Narzędzia:** IntelliJ IDEA, Git

##  Jak uruchomić?
1. Sklonuj repozytorium.
2. Zainstaluj wymagane biblioteki: `pip install textblob deep-translator`.
3. Umieść tekst do analizy w pliku `tekst.txt`.
4. Uruchom `main.py`.
